## 四、如何入库（向量化）

数据文件由 `rag/vector_store.py` 读取入库：

1. 读取 `data/` 下的 `.txt` / `.pdf` 文件；
2. `RecursiveCharacterTextSplitter` 按块切分（默认 200 字/块、重叠 20 字，分隔符 `\n\n`、`\n`、`。`）；
3. 阿里云百炼 `text-embedding-v3` 向量化，存入 Chroma；
4. 用文件 MD5 做增量去重（`md5.text` 记录已入库文件，避免重复导入）。

入库命令：

```bash
python -c "from rag.vector_store import VectorStoreService; VectorStoreService().load_documents([])"
```

> 注意：
> - 入库需要先配置 `.env` 中的 `DASHSCOPE_API_KEY`（阿里云百炼），向量持久化到 `chroma_db/`（已 gitignore）。
> - **约 2.2 万条数据向量化会产生较多 embedding 调用与耗时**，如需快速演示可只保留第一层 43 篇 + 部分分类文件（例如删除 `生态综合.txt`）后再入库。
